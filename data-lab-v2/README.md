# SeeFood DataLab 2.0

This is the isolated acquisition-first lab. Begin with `AGENTS.md`, `MISSION.md`,
`PLAN.md`, `STATUS.md`, and `LEAD_BRIEF.md`. The founder-level design is in
`docs/SEEFOOD_DATALAB_V2.md`; retained 1.0 lessons are in
`docs/DATALAB_V1_ARCHIVE.md`.

Lab code, sanitized fixtures, and cycle results belong here. Downloads, raw
pages, generated artifacts, and the shadow database stay in ignored subfolders.
The archived sibling `data-lab/` directory must not be edited.
